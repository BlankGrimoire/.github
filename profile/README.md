# BlankGrimoire

**A native, ad-free reader and personal library for the content you bring.**

BlankGrimoire is an open-source, non-commercial project. The app ships as an
**empty container**: it includes no content, no sources and no pre-configured
websites. Users add the websites they already visit, and open-source
*theme adapters* turn them into a single, private library with saved reading
progress.

## Repositories

| Repository | Description |
|---|---|
| [BlankGrimoire-iOS](https://github.com/BlankGrimoire/BlankGrimoire-iOS) | Native iOS app (Swift, SwiftUI, SwiftData, JavaScriptCore) |
| [BlankGrimoire-sdk](https://github.com/BlankGrimoire/BlankGrimoire-sdk) | Adapter contract, declarative runtime, testing and build tooling |
| [BlankGrimoire-themes](https://github.com/BlankGrimoire/BlankGrimoire-themes) | Official adapters for common website themes |

## Principles

- 🧩 **Themes, not websites**: adapters target website structures, never specific sites.
- 🫙 **Empty by design**: no domains, catalogs or content in any repository.
- 🏷️ **Attribution first**: the original site's name, logo and credits are always preserved.
- 🔐 **Secure by default**: sandboxed runtime, host allowlists, signed adapter bundles.
